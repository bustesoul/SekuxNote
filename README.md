# SekuxNote

SekuxNote 是一款本地优先的 AI 语音记录与会议整理应用。它将原始录音、实时临时稿、会后文件转写、AI 总结和基于记录的问答放在同一个工作流中，并允许用户自行配置文字 AI 与语音转写服务。

项目当前版本为 `0.1.0`，仍在持续开发中。

## 已实现功能

### 录音

- 采集 16 kHz、单声道、16-bit PCM，并在结束录音时生成标准 WAV 文件。
- 支持开始、暂停、继续和停止录音，离开录音页面后仍由应用级会话保持录音状态。
- Android 使用麦克风前台服务和持续通知；iOS 声明音频后台模式。
- 录音过程中显示实时音量反馈。
- 每条录音独立保存音频和元数据；应用异常退出后会检查并尝试恢复未完成的 PCM/WAV 文件。
- 可选接入阿里百炼 `fun-asr-realtime`，在录音时生成实时临时稿。实时转写中断不会停止本地录音。

### 音频文件转写

- 从本地选择音频文件并创建持久化转写任务。
- 支持 OpenAI Audio API 兼容服务，包括 OpenAI、Groq 和可自定义 Base URL 的兼容供应商。
- 支持阿里百炼原生 ASR：
  - `fun-asr`：异步文件精转；
  - `fun-asr-flash-2026-06-15`：短文件流式快速转写；
  - `fun-asr-realtime`：录音实时转写。
- 根据供应商能力保存时间戳、说话人和结构化句段。
- 小文件直接上传；需要分片时可配置分片时长和并发数。
- 转写任务、分片进度、结果和错误均持久化，支持停止、重试未完成分片和删除终态任务。
- 转写前检查 WAV 完整性，避免上传空文件或损坏音频。

### 记录库

- 在统一时间线中展示本地录音和文件转写任务。
- 首页显示最近记录，完整记录库支持按标题搜索。
- 可查看实时临时稿、最终转写文本、分片进度、错误信息及带说话人的时间轴句段。
- 可直接从记录或转写结果生成 AI 总结。

### AI 助手与会议总结

- 支持多个文字 AI 供应商，并可选择默认供应商和模型。
- 同时支持 OpenAI Responses API 与 Chat Completions 兼容协议。
- AI 回复以流式方式显示，对话线程和消息持久保存在本机。
- 对话可附加一条或多条录音/转写记录作为上下文。
- AI 总结与具体记录版本绑定；源文本变化后，旧总结会被标记为过期。
- 总结结果持久化保存，Markdown 内容可在渲染视图和源码视图之间切换。
- 可随时取消正在进行的文字生成。

### BYOK 与配置同步

- 文字 AI 和语音转写使用相互独立的供应商配置及 API Key。
- 支持添加多个供应商、切换默认供应商、启用/停用配置，并在设置页显式测试 API。
- 供应商配置、API Key、转写任务、AI 对话和总结均保存在本地 SQLite 数据库中。
- 可通过 WebDAV 上传或下载供应商配置快照。
- WebDAV 快照使用 PBKDF2-HMAC-SHA256 派生密钥，并以 AES-256-GCM 加密。
- 配置同步只包含供应商设置和 API Key，不上传录音、转写记录、AI 对话或总结。

### 界面

- 手机使用底部导航栏，宽屏桌面使用侧边导航栏。
- 提供首页、AI 助手、记录库和设置四个一级入口。
- 支持浅色/深色系统主题。
- 支持英文、简体中文和繁体中文界面。

## 数据与隐私

SekuxNote 默认将用户数据保存在设备本地：

- iOS：应用 Documents 目录；
- 其他原生平台：应用 Application Support 目录；
- 录音：每条记录独立保存 WAV 和元数据；
- 导入音频：仅为失败任务的断点重试保留本地副本，删除任务时同步删除；
- 网络请求：只在用户启用实时转写、提交文件转写、调用文字 AI 或执行 WebDAV 同步时发生。

本地数据库和 WebDAV 登录设置目前不提供额外的设备端加密层，应依赖操作系统账户、磁盘加密和应用沙箱保护。远端 WebDAV 配置快照本身经过加密。

## 运行项目

环境要求：

- Flutter SDK；
- Dart SDK `>=3.10.7 <4.0.0`；
- 运行录音功能的设备需要授予麦克风权限；
- Apple 平台构建需要可用的 Xcode/CocoaPods 环境。

```bash
flutter pub get
flutter run -d macos
```

也可以将 `macos` 替换为本机可用的 Android 或 iOS 设备 ID：

```bash
flutter devices
flutter run -d <device-id>
```

首次使用前，请在“设置”中分别配置：

1. 文字 AI 供应商，用于 AI 对话和会议总结；
2. 语音转写供应商，用于文件转写；
3. 如需边录边转，添加并设为默认的阿里百炼原生 ASR 配置。

## 当前限制

- 项目仍处于开发阶段，尚未提供应用商店发布包或稳定性承诺。
- 录音实时转写目前只接入阿里百炼 `fun-asr-realtime`；OpenAI 兼容配置主要用于文件转写。
- 录音结束后不会自动生成会后最终稿；当前可使用实时临时稿生成总结，或单独将音频文件提交到文件转写工作台。
- 尚未实现应用内音频播放、录音导出和录音重命名。
- WebDAV 当前只同步供应商配置，不同步录音、转写任务、AI 对话或总结。
- 实际可用的模型、文件大小、音频格式、说话人分离和时间戳能力取决于所配置的供应商。
